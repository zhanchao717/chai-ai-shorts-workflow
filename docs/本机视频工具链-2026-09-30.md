## 一、可用的两个 wrapper（已创建）

### `~/bin/ffmpeg`

**已改用 Codex 工程内附带的真实静态构建**（45MB，ffmpeg 6.0，含 libass/freetype/fontconfig，比 Remotion 那个精简构建完整）：

```bash
exec "<REPO>/videos/openai-devday-226/bin/ffmpeg" "$@"
```

> 备选：Remotion 自带的构建在 `node_modules/@remotion/compositor-darwin-arm64/ffmpeg`
> （需 `DYLD_LIBRARY_PATH` 指向同目录；`--disable-filters` 后只剩少量滤镜，缺 `color`/`testsrc`）。

- 真能编码：已实测 `-c:v libx264 -pix_fmt yuv420p -c:a aac` → 正常 mp4
- **缺的 filters**：`color`、`testsrc` 等合成源没有（configure 里 `--disable-filters` 后仅挑了少量）
- 可用 muxers：`mp4 mov matroska webm wav mp3 ogg opus image2 gif h264 hevc mpegts null` 等
- 可用音频编码器：`aac libfdk_aac libmp3lame opus libopus pcm_s16le pcm_s24le`

### `~/bin/ffprobe`（**纯 Python shim**，仍是唯一可行方案）

Remotion 自带的 `ffprobe` **会挂起**——`-version` 都卡死；Codex 用的 zsh 包装（切到 compositor 目录再执行）**同样挂起**。所以必须用自写 shim：

- **MP4**：解析 `moov/mvhd` 取时长，各 `trak/mdia/hdlr` 判定 video/audio
- **MP3**：跳过 ID3v2，解析 MPEG 帧头取码率/采样率/时长
- **图片**：`format_name` 必须是 `jpeg_pipe` / `png_pipe`（**不是** `mjpeg`/`png`），否则报
  `do not match their authored media element type (expected: image)`
- 输出 ffprobe 兼容 JSON（`-show_streams` / `-show_format` / `-of json`）

**为什么必须支持 MP3**：hyperframes 用 `profile.hasAudioStream` 判断资产类型；MP3 返回 0 条流会报
`N composition asset(s) do not match their authored media element type (expected: audio)`。

## 三、HyperFrames 渲染

缓存里已有多版本，`0.8.96` 可离线解析（`npx --yes hyperframes@0.8.96`）。渲染必须带：

```bash
export PATH="$HOME/bin:$HOME/.nvm/versions/node/v26.5.0/bin:$PATH"
export HYPERFRAMES_FFPROBE_PATH="$HOME/bin/ffprobe"
export HYPERFRAMES_FFMPEG_PATH="$HOME/bin/ffmpeg"
cd videos/<slug> && npx --yes hyperframes@0.8.96 check   # 先 check
npx --yes hyperframes@0.8.96 snapshot --at "3,12,25" --describe false   # 再看画面
npx --yes hyperframes@0.8.96 render
```

### 已知阻塞：内置音频混音失败

`dist/chunk-427VCI2W.js` 的 `mixAudioTracks()` 构造的 ffmpeg 参数是：

```
… -acodec aac -b:a 192k -t <dur> -y <outputPath>
```

**没有 `-f`**，而 `outputPath` 无扩展名 → ffmpeg 报
`Unable to choose an output format … Invalid argument`（退出码 234），渲染被 correctness warning 拦下。

**绕过办法（当前采用）**：把 `<audio>` 元素暂时从 HTML 移除 → 渲染无声视频 → 自己混音：

```bash
~/bin/ffmpeg -i video.mp4 -i v1.mp3 … -i v5.mp3 \
  -filter_complex "[1:a]adelay=0|0[a1];[2:a]adelay=7956|7956[a2];…;[a1][a2]…amix=inputs=5:duration=longest:normalize=0[aout]" \
  -map 0:v -map "[aout]" -c:v copy -c:a aac -b:a 192k -shortest -y out.mp4
```

（`adelay` 用毫秒；`amix` 的 `normalize=0` 保留各段原始音量）
