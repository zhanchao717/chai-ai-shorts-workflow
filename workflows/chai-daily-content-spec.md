# 柴主编 · 每日一条内容生产线规范（v1，2026-10-10）

本文件是**可重复执行的作业规范**。目标：每天产出 1 条"有含金量"的内容，且每条都能被数据和受众验证。
配套：[调研报告](../research/douyin-niche-research-2026-10-10.md) ｜ [选题清单](../research/topic-plan-2026-10-10.md) ｜ [主页审计](../research/profile-audit-2026-10-10.md)

## 0. 三条不可违背的前提（来自实读数据）

1. **受众是中老年**：≥41 岁占 51%（>50 岁 37%），国产安卓过半，粉丝兴趣第一位是"随拍"。**写稿时默认对方不会用电脑、手机字号要能看清。**
2. **短板是留存不是分发**：播放量超过 90% 同类，但完播率 5.7%（低于 74% 同类）、平均播放时长仅 9.85 秒。**每 10 秒必须有一个"值得留下来"的理由。**
3. **主页转化只有 1.25%**：内容之外，简介/置顶/封面必须同步修。**每条结尾都要引导到主页，不只是引导评论。**

## 1. 选题准入：四问清单（少于两问直接砍）

写任何一条之前，先确认它能回答下列问题中的**至少两个**：

| # | 问题 | 观众原话证据 |
|---|---|---|
| 1 | 要花多少钱？免费还是订阅？ | 「之前试的都先要开会员」 |
| 2 | 我这台设备行不行？电脑什么配置？手机行不行？ | 「必须电脑吗？手机行不行」 |
| 3 | 国内能不能用？直连还是要账号？ | 「国内怎么下载」 |
| 4 | 到底去哪下载？给具体路径 | 「我连下载都不知道怎么下载」 |

**另外必须有两样：**

1. **一句能让观众带走的话（判词）**，且它得是"结论"不是"提问"。
2. **一个可以被看见的具体结果。** 这是硬门槛，比四问还重要。

### 什么算"具体结果"

- **一支成片**（哪怕只有 20 秒）
- **一张能保存、能照抄的表**（角色对照表 / 分镜表 / 节奏表）
- **一组对照**（A 方案和 B 方案差多少，有画面）
- **一套能照做的步骤**（跟完能出东西）
- **一个明确的数字**（花了多少、做出多少分钟、差几倍）

### 什么不算

- "讲讲 X 是什么"
- "分析一下 Y 的趋势"
- "盘点 N 个平台"
- "免费能做到哪一步"（有结论，但没有一个能看见的东西）

**为什么这条是硬门槛**：我们实读的数据里，你失败最多的一类（大厂新闻，每条只换 0.97 个粉）全都是"讲清楚了一件事，但观众手里什么都没多出来"。而头部爆款的钩子统计里，**"晒结果 + 反转"是优先级最高的一种**。
**观众记不住观点，只记得住东西。**

## 2. 结构与时间码（75 秒基准）

| 段 | 时间 | 作用 | 硬要求 |
|---|---|---|---|
| 钩子 | 0–3s | 说出他的处境，不是介绍话题 | 用纠错/损失句式；不出现"你知道吗""大家好" |
| 事实锚点 | 3–14s | 先承认"不是你的错" | 引用真实评论原话（打码），建立"我懂你" |
| 讲清机制 | 14–40s | 只讲**一个**关键机制 | 分 2–4 个小点，每点配真实界面截图 |
| 影响谁 | 40–58s | 落到一个具体判断方法 | 给出可操作的"看哪里" |
| 限制条件 | 58–70s | 价格 / 地区 / 设备 / 未证实部分 | 不回避，主动说清 |
| 判词 | 70–75s | 固定结论标签 | 从判词库选，不即兴发挥 |

**每 15 秒一个"钩子回收"**：一句短句把观众拉回来（"记住这一点""这就是关键"）。

## 3. 判词库（固定，形成人设）

| 标签 | 什么时候用 |
|---|---|
| `先分清形态，再谈上手` | 下载/安装类 |
| `今天不用装` | 工具还不好用 |
| `值得记住` | 有真实价值 |
| `先别付费` | 免费够用或价格不值 |
| `国内能用` | 验证过国内可用 |
| `只影响这类人` | 与多数人无关 |
| `你这台机器够用` | 硬件类 |
| `再等一版` | 版本还不成熟 |

## 4. 封面与标题规范（对准 4.49% 点击率）

**封面三条硬规则：**
1. 主标题**至少占画面高度 1/4**，手机上不放大也能读。
2. 一句话只讲**一个具体结果或损失**，不出现"赋能/生态/范式"这类词。
3. 底色与配图**统一风格**（建议：深底 + 大号亮字 + 一个真实界面局部），不要每期换风格。

**标题从"提问"改成"给结论"：**

| ❌ 现在 | ✅ 改成 |
|---|---|
| Gemini 4 发布了，还用不上？ | Gemini 4 很强，但你今天用不上：原因就一个 |
| 洗碗叠衣服 也能交给它？ | 机器人能洗碗叠衣服了，但有个前提 |
| 更细、更快 为何还报错 | 天气预报每小时更新，为什么还报不准 |

## 5. 每日作业流程（约 90 分钟）

1. **选题**（5 分钟）：从[选题清单](../research/topic-plan-2026-10-10.md)取当天条目；若当天有热点，用四问清单判断能否套用。
2. **取证**（20 分钟）：查到官方原文/页面截图。**凡是"我说"都要有出处；没有出处的改用"官方称"。**
3. **写稿**（30 分钟）：按第 2 节结构填。先写判词，再倒推钩子——**先想清楚让他带走什么，再想怎么开头。**
4. **过 DBS 三件套**（10 分钟，**强制，不可跳过**）：
   - `dbs-ai-check`：查 AI 写作特征（重点看「不是 X 是 Y」密度是否超过 3 次／800 字、破折号是否承担了过多停顿）
   - `dbs-resonate`：查核心机制是否单一、五维度（沉默解除／满足动机／立场框架／传播入口／信念结构）是否成立
   - `dbs-hook`：查开头前三秒——**独立性、可信度、悬念有没有被自己吃掉**
   - 发现实质问题就改，改完复检通过才算完稿
5. **自检**（10 分钟）：过下面的发布前检查单。
6. **制作**（25 分钟）：按文案的画面提示出图/录屏。
7. **发布**（5 分钟）：标题用结论式，话题标签 4–5 个。

## 6. 发布前检查单

- [ ] 四问至少回答两个
- [ ] 前 3 秒出现了"他的处境"或"他的损失"
- [ ] 判词是结论，不是提问
- [ ] 封面主标题占画面高度 ≥1/4，手机可读
- [ ] 全片无"亲测/我测过"等未做过的声明（你的合规红线）
- [ ] 结尾引导到主页（不只是评论）
- [ ] 事实都有出处，未证实部分已写明"官方称/尚未证实"

## 7. 发布后 24 小时回看（这是生产线能自我进化的关键）

| 指标 | 及格线 | 不达标就先改什么 |
|---|---|---|
| 2 秒跳出率 | **< 40%**（现状 43–52%） | 改前 3 秒，不改整片 |
| 5 秒完播率 | > 50%（现状 40.9%） | 改钩子与画面节奏 |
| 封面点击率 | > 6%（现状 4.49%） | 改封面字号与结论 |
| 主页访问/播放 | > 2%（现状 0.9%） | 加人设与主页引导 |
| 单条吸粉 | > 3（现状约 1） | 检查"关注理由"是否成立 |

**每周复盘一次**：把当周 7 条按上表排序，**只改最差那一项，别同时改所有变量**。

## 8. 红线（不可越）

- **不虚构个人经历。** 没做过的事不说"我用了／我测了／我试过"。
- **不写"非本人实测"这类免责声明。** 解释类内容不需要声明。**力气应该花在"让选题不需要实测"上，不是花在免责上。**
- **不需要实测的题怎么做：** 讲机制、讲规则、讲官方原文、讲公开数据，并标明出处（"公告里写""官方说"）。**出处本身就是可信度**，比任何免责声明都有用。
- **避开必须实测才能讲的题：** 效果对比、参数实测、跑分、上手体验——这几类没有第一手材料就不碰。
- 不提供规避网络管理的方法，只说"需要额外网络条件"，把判断权交给观众。
- 不搬运他人成片。
- 不承诺收益、不做投资类判断。
